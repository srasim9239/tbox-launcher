# TBox Launcher как домашнее приложение по умолчанию (без диалога выбора)

Инструкция для Jetour Dashing (ГУ на Android 9). Проверено 06.08.2026.

## Суть

На этой прошивке штатная команда `cmd package set-home-activity` формально
отвечает «Success», но выбор лаунчера при загрузке всё равно появляется:
создаваемый ею фильтр содержит категорию `DEFAULT`, которой нет в реальном
HOME-интенте системы, поэтому предпочтение не применяется.

Рабочий способ — **отключить штатный лаунчер `com.wt.launcher3`** командой
`pm disable-user`. Данные приложения при этом **не удаляются**, операция
полностью обратима одной командой. После отключения единственным полноценным
HOME-приложением остаётся TBox Launcher — система запускает его сразу,
без диалога выбора, в том числе при загрузке.

## Требования

- Установленный TBox Launcher (`ras.dashing.tbox.launcher`).
- Доступ по `adb` (USB или ГУ и ПК в одной сети, отладка включена).

## Установка по умолчанию

```bash
# 1. (необязательно) посмотреть кандидатов в HOME
adb shell "cmd package query-activities -a android.intent.action.MAIN -c android.intent.category.HOME --components"

# 2. Отключить штатный лаунчер
adb shell "pm disable-user --user 0 com.wt.launcher3"
# ответ: Package com.wt.launcher3 new state: disabled-user

# 3. Проверить, что HOME теперь резолвится в TBox Launcher
adb shell "cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME"
# ожидаем: ras.dashing.tbox.launcher/vad.dashing.tbox.LauncherHomeActivity

# 4. Перезагрузить ГУ — после загрузки сразу TBox Launcher, без выбора
adb reboot
```

## Откат

```bash
adb shell "pm enable com.wt.launcher3"
```

После этого возвращается штатное поведение: при нажатии «Домой» снова
появится диалог выбора лаунчера, где можно выбрать штатный (`Лаунчер` /
`wt.launcher3`) и назначить его «Всегда». Данные и настройки штатного
лаунчера сохраняются за время отключения.

## Предупреждения

- **Не удаляйте TBox Launcher, пока штатный отключён.** Иначе останется
  только системный FallbackHome (заглушка Настроек). Лечится по adb:
  `pm enable com.wt.launcher3`.
- OTA-обновления TBox Launcher на дефолт не влияют: имя пакета не меняется.
- Виджеты/карточки штатного рабочего стола на время отключения недоступны —
  они часть `com.wt.launcher3`.
- После перепрошивки или сброса ГУ процедуру нужно повторить.
- Проверить состояние в любой момент: `adb shell "pm list packages -d | grep launcher"`.

## Почему это безопасно

`pm disable-user` — штатная команда Android для отключения приложения
«для пользователя» без удаления: APK и данные остаются на месте,
приложение просто перестаёт быть видимым для системы. `pm enable`
возвращает всё как было. Перезагрузка не требуется ни для отключения,
ни для возврата.
