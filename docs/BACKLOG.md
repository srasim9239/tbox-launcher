# Бэклог TBox Launcher

Журнал задач от пользователя. Статусы: ✅ выполнено, 🔧 в работе, ⬜ ожидает.

## Текущие

| Статус | Задача | Примечание |
|--------|--------|------------|
| 🔧 | Парктроники: 3D-сонар-дуги вокруг модели авто в ADAS-зоне | Радар-листенер mbCAN (`registRadarSensorListener`, 12 каналов → 6 зон), оверлей `LauncherPdcOverlay` (кольца: ≤35см красные пульс, ≤75 янтарь, ≤150 зелёные). Ждёт проверки на авто |
| 🔧 | Режим симуляции ADAS (круиз, полосы, BSD L/R, объект впереди, парктроники перед/зад) | Блок «ADAS / ассистенты» в скрытой карточке симуляции; подменяет live-состояние на главной |
| 🔧 | ADAS-зона: BSD-маркер отображается слишком высоко (как преграда сбоку), должен быть сзади по диагонали | Зона смещена с y≈0.62h на y≈0.78h (задний угол). Ждёт проверки в движении |
| ⬜ | Файл-пикер: краш при открытии выбора файла из freeform-приложения (нет DocumentsUI на ГУ) | нужен гард + возможно свой файл-менеджер в Monitor |

## Выполненные (сессия 10.08.2026)

| Статус | Задача | Решение |
|--------|--------|---------|
| ✅ | Root-guard «назад»: не закрывать freeform-приложение на его главной странице | Код guard'а был на месте; на авто-ГУ не хватало разрешений и accessibility-сервиса. Проверено на стенде: `skip root BACK`, задача не закрывается. ВАЖНО: аппаратная/сторонняя кнопка «назад» (nu.back.button) идёт мимо guard'а — работает только кнопка в доке |
| ✅ | Не работали напряжение, ассистенты, климат в автономном лаунчере | Встроена вендорская mbCAN-библиотека: `com.mengbo.*` (129 java-файлов) + `libmbCan/libmbcanclient/libmbutils/libc++` (arm64-v8a) из монорепо Monitor. 0.2.1 |
| ✅ | Home/Back не работают, оверлеи под freeform на авто-ГУ | На авто-ГУ не были выданы разрешения; выданы по docs/SETUP_RU.md |
| ✅ | Не отображался процент топлива | `fuelLevelPercentageFiltered` считается только в активной поездке; добавлен фолбэк на сырой `fuelLevelPercentage` (левая панель + настройки авто). 0.2.2 |
| ✅ | Кнопка задних противотуманок не работала никогда | Свитч в настройках слал `SetProperty`, а в реестре для 136 только `ToggleBinary` → «Set unsupported». Разрешён explicit SET {off,on} для ToggleBinary. 0.2.2 |
